# Techno-Economic Optimization of a Solar-Powered Alkaline Electrolyzer System

## Overview

This project focuses on the techno-economic analysis of a
solar-powered alkaline electrolyzer system for green hydrogen
production.

The study evaluates hydrogen production, CAPEX, OPEX and
Levelized Cost of Hydrogen (LCOH) for different solar and
electrolyzer configurations.

## Objectives

- Estimate hydrogen production from solar-powered electrolysis.
- Calculate CAPEX, OPEX and LCOH.
- Compare different solar and electrolyzer capacities.
- Study the effect of electricity cost, efficiency and utilization.
- Identify a suitable solar-to-electrolyzer configuration.
- Develop an ML model for LCOH prediction.
- Validate the calculated results using published values.
